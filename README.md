# Data Management

Data Management is a community-developed data handling and replication plug-in available on all Obsidian-compatible platforms. It leverages robust server solutions such as CouchDB or object storage systems (such as MinIO, S3, and R2) to ensure reliable data management across devices.

Additionally, it supports peer-to-peer data replication using WebRTC, enabling direct data management between devices without relying on an external server.

## Features
- Replicate vaults efficiently with minimal network traffic.
- Handle conflicting modifications effectively with automated merging for simple conflicts.
- Support open-source self-hosted backends and object storage.
- Support end-to-end encryption.
- Manage configuration, snippets, themes, and plug-in data.
- Support WebRTC peer-to-peer data handling.

## Information in the Status Bar

Data management status is displayed in the status bar with indicators:
- Activity indicators for remote connection
- Status indicators (idle, active processing, error)
- Statistical indicators for uploaded and downloaded chunks and metadata
- Progress indicators for ongoing vault operations
